# MuxTV

MuxTV — бесплатное open-source приложение для Android TV, Google TV и Fire TV, которое превращает пользовательские IPTV-источники в единое, устойчивое и удобное телевидение.

Ключевая идея проекта: пользователь управляет каналами, а приложение самостоятельно управляет плейлистами, дублями, EPG, качеством и резервными потоками.

## Статус

Проект находится на стадии архитектурного фундамента. Код приложения ещё не создан. Зафиксированы продуктовые границы, базовая архитектура, технологический стек, требования к качеству и план реализации.

## Документация

Вся рабочая документация и машинно-читаемые метаданные проекта находятся в [`.work`](.work/README.md).

## Основные принципы

- TV-first интерфейс, полностью рассчитанный на D-pad и пульт.
- Никакой рекламы, обязательной регистрации или встроенных платных каналов.
- Local-first: источники, учётные данные, история и настройки остаются на устройстве.
- Android TV first; другие платформы добавляются только через чёткие контракты.
- Media3 как основной playback engine; Rust и libmpv — только после измеримой необходимости.
- Распространение через GitHub Releases, без обязательной публикации в Google Play.
